\# Gestor de Tareas



Aplicación de consola desarrollada en Java para gestionar una lista de tareas.



\## Autor



Dominik



\## Requisitos



\- Java 17 o superior

\- Maven 3.8 o superior



\## Cómo ejecutar el programa



El proyecto se puede ejecutar desde NetBeans o mediante Maven.



\## Funcionalidades



\- Añadir tareas.

\- Mostrar tareas.

\- Completar tareas.

\- Eliminar tareas.



\## Tecnologías utilizadas



\- Java

\- Maven

\- Git

\- GitHub
